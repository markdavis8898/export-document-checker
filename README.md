# Export Document Checker

**Export compliance** validation tool — verifies that your international trade documentation meets regulatory requirements.

## Features

- Document completeness checklist
- Country-specific export requirements
- Real-time compliance status
- Missing document detection

## Usage

```bash
python3 checker.py --destination Germany --incoterms CIF
```
